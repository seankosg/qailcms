## 2. 권한이 어떻게 작동하나

- 임포트 파일에 남의 담당 행이 섞여 있어도 **전송 전에 서버가 행 단위로 판정**해 걸러낸다.
  판정 기준은 파일 값이 아니라 **DB 에 저장된 현재 담당자/팀** 이므로, 파일에 자기 이름을 적어 넣어도
  남의 행을 가져갈 수 없다.
- 걸러진 행은 조용히 사라지지 않고 화면 상단 배너에 "제외 N건 / 역할 / 사유" 로 표시된다.
- 화면 차단과 별개로 **DB 자체에도 같은 규칙**을 걸어 두었다(직접 접근으로도 우회 불가).

## 4. 남은 사항 / 판단 필요

1. **배포 여부** — 지시대로 배포하지 않았다. 승인 시 바로 반영 가능.
2. **PO 담당자 소급 연결** — PIC PO / ENG PO 값이 아직 비어 있어 소급 연결 대상 0건.
   PO 이름이 포함된 파일을 한 번 임포트하면 자동으로 채워진다.
