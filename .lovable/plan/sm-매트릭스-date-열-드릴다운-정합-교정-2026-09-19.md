# SM 매트릭스 Date 열 · 드릴다운 정합 교정

## 1. 지적 셀 실측 (Plot D · Tower · TENANT · ARCH · Rect, 기준일 2026-09-19)

| 항목 | 화면 표시 | 실측 정답 |
| --- | --- | --- |
| Level 66 Date (잔여 4건) | 10/Mar (2027-03-10) | 2026-10-23 (잔여 4건의 최대 계획일) |
| Column Total Date (잔여 42건) | 10/Mar (2027-03-10) | 2027-02-21 (잔여 42건의 최대 계획일) |
| Level 66 드릴다운 | 실적 Rectified ≤ 2026-09-19 → 종결 7건 | 잔여 4건이 나와야 함 |

원인 2가지를 확정했습니다.

1. **Date 값의 대상 집합이 틀렸습니다.** 날짜 집계가 셀 안의 **모든 항목**에서 계획일 최댓값을 뽑습니다. 이미 완료된 항목(61709·62028·62029 — 계획 2027-03-10, 실적 2026-08-29 완료)의 먼 계획일이 섞여, 잔여 항목에는 존재하지 않는 날짜가 표시됩니다. Column Total도 같은 이유이며, "그 컬럼의 가장 늦은 날짜"는 맞게 뽑고 있으나 대상이 잔여가 아니라 전체입니다.
2. **드릴다운 조건이 셀과 반대입니다.** 잔여·Date 셀을 눌러도 `실적일 ≤ 기준일`(=완료 항목) 필터로 이동합니다. 그래서 잔여 4건 대신 완료 7건이 보입니다.

## 2. 전체 블록 전수 재확인 (같은 오류 범위)

기준일 2026-09-19, 잔여가 있는 셀만 대상으로 전체 블록·스테이지를 대조했습니다.

| 스테이지 | Plot D 잔여 셀 / 날짜 틀린 셀 | Plot C 잔여 셀 / 날짜 틀린 셀 | Plot C 지연(빨강) 표시가 뒤집히는 셀 |
| --- | --- | --- | --- |
| Rect | 677 / 47 | 872 / 89 | 34 |
| Pre-Ins | 704 / 44 | 991 / 91 | 21 |
| DAR-Ins | 704 / 51 | 991 / 121 | 31 |
| Closed | 741 / 44 | 1,069 / 33 | 15 |
| H/O | 742 / 47 | 1,070 / 27 | 7 |

지적하신 셀만의 문제가 아니라 **같은 오류가 전 블록에 걸쳐 총 594개 셀**에서 나타납니다. Plot D H/O에는 잔여 항목에 계획일이 아예 없는데도 완료 항목의 계획일이 표시되는 셀이 4개 있고, Plot C에서는 108개 셀의 지연(빨강) 강조가 잘못 켜지거나 꺼집니다. 드릴다운 불일치는 잔여 계열 모드의 모든 셀에 공통입니다.

## 3. 고칠 내용

### 1) Date 집계를 잔여/완료로 분리 (DB)
날짜 집계 함수를 스테이지별 두 갈래 최댓값으로 재작성합니다.
- 잔여(해당 스테이지 실적일이 없거나 기준일 이후)만 모아 **계획일 최댓값** → 미완료 셀에 표시
- 완료(실적일 ≤ 기준일)만 모아 **실적일 최댓값** → 잔여 0 셀에 표시
- 완료 판정은 기존 정본과 동일한 식을 재사용하고, 셀·행·빌딩·열·블록 소계는 현행 조립 유틸에서 그대로 최댓값으로 접습니다. 구 시그니처는 같은 마이그레이션에서 제거합니다.

Column Total 날짜도 이로써 "그 컬럼 잔여 항목 중 가장 늦은 계획일"로 자동 정합되고, 지연 강조도 함께 바로잡힙니다.

### 2) 잔여 셀 드릴다운을 잔여 조건으로 (DB + 화면)
- 검색 함수군에 `잔여(스테이지, 기준일)` 조건을 추가해 완료 판정 정본이 false인 행만 남깁니다(규칙 재구현 없음).
- 매트릭스 드릴다운은 모드별로 분기: 잔여 개수·잔여 %·잔여+Date·Each Date → 잔여 조건, 개수·% → 현행 완료 조건 유지, Issued 열은 현행 유지.
- Raw Data 화면에 어떤 조건으로 들어왔는지 보여주는 칩(`Remaining — <스테이지> @ <기준일>`)을 붙입니다.

### 3) 시행 후 검산
전 블록·스테이지를 위 표와 같은 방식으로 다시 집계해 날짜 틀린 셀 0, 지연 강조 뒤집힘 0을 확인하고, 2027년 이후 날짜 셀 중 무작위 10개는 화면값 ↔ 실측값 ↔ 드릴다운 행수까지 대조해 보고합니다. 엑셀 다운로드 값도 같은 기준으로 대조합니다.

## 4. 바뀌지 않는 것
매트릭스 열 구성·토글·색상·문구·엑셀 형식은 그대로입니다. 잔여 개수·%와 Ready/지연 강조 규칙 자체도 변경 없으며, 날짜의 대상 집합만 바로잡습니다.
