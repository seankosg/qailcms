# TOC 모듈 — 2단계: 원천 파일 1회 적재(시딩)

## 진행 상황 (앞 단계 완료분)

1단계(자료 구조)와 0단계(모듈 등록)는 적용 완료했습니다. 항목·단계 카탈로그(준비 항목 7개, 단계 12개)·단계 진행·교육 세션·연결·세션 피드백·변경 이력·임포트 로그·설정 표, 경보용 점검 목록, T&C 미완 항목의 교육 실적 입력 차단 장치, 권한·백업 등록까지 들어갔고 자체 점검 10건을 통과했습니다.

## 원천 파일 실측 (지시서 기대치와 대조)

| 항목 | 원천 실측 | 지시서 기대 | 판정 |
|---|---|---|---|
| SOW 항목 | 104건 (Mech 56 / Elec 41 / Civil 7) | 104 | 일치 |
| 외부 F&F 항목 | 11건 | 11 | 일치 |
| 인수증 상태(SOW) | 승인 36 / 검토 중 25 / 미제출 43 | 36 / 25 / 43 | 일치 |
| 인수증 상태(F&F) | Code C 7 / 미제출 4 | 7 / 4 | 일치 |
| 교육 세션 | 99건 (실시 88, 평가서 수령 71) | 96 / 71 | 세션 수 99(파일 갱신분), 평가서 71 일치 |

두 시트의 열 배치가 서로 다릅니다(SOW는 머리글 5~6행·팀이 B열, F&F는 머리글 2~3행·팀이 A열). 각각 별도 판독 규칙으로 읽고, 열 위치가 아니라 머리글 문구로 찾습니다.

## 확인이 필요한 두 가지

**1. 교육 연결용 매핑 파일이 업로드되지 않았습니다.** 지금 올라온 것은 SOW 파일과 교육 현황 파일 두 개뿐입니다. 그래서 이 계획은 **장비명 ↔ 교육 주제 자동 대조**로 연결을 만들고, 확실하지 않은 건과 미연결 건을 검수 목록(엑셀)으로 제출해 확정받는 방식으로 씁니다. 매핑 파일을 올려 주시면 그 대응을 그대로 쓰고 자동 대조는 검증용으로만 씁니다.

**2. "평가서는 날짜 기준" 선택의 결과.** 원천 교육 현황에는 평가서 수령일이 **날짜로 적힌 곳이 없습니다**(전부 `Received` 같은 상태값이며, 실시일도 18건이 공란이고 일부는 `Monday , june 22, 2026` 형태의 글자입니다). 날짜 기준을 유지하면 평가서 수령 71건이 **완료로 잡히지 않고**, 교육 준비 항목이 거의 전부 미완으로 남아 이미 인계된 36건도 "준비 중"으로 보입니다.

그래서 이 계획은 날짜 기준을 유지하되 다음을 함께 넣습니다.
- 세션의 상태값(`Conducted`, `Received`)은 그대로 저장하고 화면에 보여 줍니다.
- 실시일은 글자로 적힌 날짜까지 해석해 최대한 채웁니다(해석 실패분은 원문 그대로 비고에 남깁니다).
- 평가서는 날짜가 없으므로 **"수령 확인, 일자 미상 71건"** 카드를 대시보드와 적재 보고서에 명시해, 담당자가 일자를 채우면 자동으로 완료로 바뀌게 합니다.

이 결과가 받아들여지지 않는다면 평가서 판정을 상태 기준으로 바꾸는 편이 맞습니다 — 그 경우 알려 주세요.

## 무엇을 적재하는가

**항목 115건** (SOW 104 + 외부 F&F 11)
- 시스템 분류·항목 번호·장비명·위치·담당 트레이드(원문 Mech/Elec/Civil 보관, 권한 판정용 코드로는 Civil→ARCH), 인수증 번호·상태·인계 예정일, T&C 및 준공도면 원문 수량
- 담당자 칸은 빈칸 유지

**단계 진행** (항목별 최대 12행)
- T&C·OMM·자산 태그·준공도면·인수증 응답: 상태값 그대로 적재(일자 없는 완료는 상태만, 일자 대입 없음)
- 원천이 `N/A`인 칸은 "해당 없음"으로 표시해 준비도 분모에서 빠지게 함
- 외부 F&F 11건은 T&C·자산 태그·준공도면 칸이 원문에 없으므로 "해당 없음"으로 적재(준비도 분모 3)
- 인수증 제출일·승인일은 날짜가 있는 그대로

**교육 세션 99건 + 세션 피드백**
- 주제·분야·실시일·실시 상태·IFM 판정·평가서 상태
- IFM 피드백 / HDEC 회신 / IFM 재검토 / HDEC 2차 회신 장문 4개를 세션 피드백으로 이관

**항목↔세션 연결**
- 장비명과 교육 주제를 정규화해 대조(완전 일치 → 부분 일치 → 미연결). 판단이 갈리는 건은 자동 연결하지 않고 검수 목록으로 남깁니다.

적재는 안전장치를 우회하는 전용 경로(적재 스위치)로 넣고, 적재 후 경보 목록에서 "T&C 미완인데 교육 진행" 건수를 보고합니다.

## 검산 (적재 직후 보고할 관계식)

- 항목 수 = 104 + 11 = 115
- 인수증 상태 분포 = 원천 분포(승인 36 / 검토 25 / 미제출 43 / Code C 7 / F&F 미제출 4)
- 세션 수 = 99, 평가서 `Received` = 71, 실시 = 88
- 준비 항목 매트릭스 셀 합 = 항목 수 × 7
- 외부 F&F 11건이 "인수증 준비 완료"로 잘못 뜨지 않는지 (원천은 Code C 7 / 미제출 4)
- 교육 연결: 연결된 세션 수 · 미연결 항목 수 · 검수 필요 건수
- "T&C 미완인데 교육 진행" 경보 건수
